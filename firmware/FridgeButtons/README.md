# 三按键输入诊断（尚待按键实测）

显示部分复用已通过实体屏验收的 Z96 配置。启动只刷一次 BUTTON TEST 页面；按键不会触发刷屏或修改食材库存。
按键：GPIO4 / GPIO5 / GPIO13，仅设置输入，40ms 去抖。
V2 默认 INPUT_PULLUP、低电平按下（本机实测有效）；卖家资料未确认按键接地/接电源，因此默认极性尚待实测，不能直接作为正式交互配置。

115200 串口命令：s 打印电平；v 切换 INPUT_PULLDOWN/高电平按下；g 切回 INPUT_PULLUP/低电平按下。串口模式切换不修改接线，不向引脚输出电平。
实测时先在默认模式依次按三个键；应每个键产生 PRESS 和 RELEASE 两条，GPIO对应独立。无响应时再切换g模式复测。不要把无响应直接判定按键损坏。

Arduino IDE：打开本目录 FridgeButtons.ino，保留 .h/.cpp；AirM2M_CORE_ESP32C3，Flash4MB，GxEPD2 1.6.9/ESP32 core3.1.0，上传端口 COM4（需确认仍为该设备）。

本固件保持运行以监听按键，不是低功耗正式版。屏幕已休眠；主控未进入深睡。完成按键映射验证后再实现页面切换，并限制全刷频率。

2026-11-07实测：用户确认BUTTON TEST已显示；上拉/下拉模式未捕获实体键事件，下拉持续监听期间各键按住1秒也无事件。按键验收未通过，GPIO映射与极性未确认，不应直接用于正式交互。

## V2：设备端累计诊断
启动画面 BUTTON TEST V2。按模式分别累计每个GPIO的原始(raw)及40ms去抖(stable)变化数。s查询及每10秒自动输出均包含累计数、运行毫秒和重启原因。读取串口不清零；重新启动/断电清零，因此仅限本次运行，不是永久存储。模式切换本身不计数。无需保持电脑持续监听即可事后查询，但按键导致重启时需结合运行时间和重启日志判断。

V2实测：HIGH模式，用户按完后查询运行203520ms，三路raw/stable全0。排除电脑错过日志；尚不能确认物理按键映射。等待设备外观/对应批次资料核对。

最新验收：上拉模式累计查询UPTIME_MS=396457，GPIO4/5/13 raw及stable分别6/6/8，松开后全高。三路输入均有响应。默认已恢复上拉；此前下拉无响应不代表按键损坏。累计总数不能确定每个实体键的空间顺序，仍待逐键带序号验证。
