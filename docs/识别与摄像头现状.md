# 识别与摄像头：现在到哪一步了

> 这份文件回答两个问题：识别做到什么程度、摄像头还差什么。
> 最后一步附了「怎么用确认数据把准确率提上去」的 SQL，不靠拍脑袋。

---

## 一、现在实际用的识别（不是规划，是线上跑的）

| 环节 | 现状 | 说明 |
|---|---|---|
| 输入 | 手机浏览器摄像头（连拍 3 帧）或相册照片 | 摄像头只在这台设备上取帧，不传原图 |
| 预处理 | 480×480 居中裁切，模糊帧按拉普拉斯方差 < 45 丢弃 | 手抖/没对焦的帧直接不进投票 |
| 模型 | 端侧 9 类 TFLite（MobileNetV3-Small 微调，3.7 MB） | 类目：鸡蛋/番茄/青菜/牛奶/香菇/猪肉/豆腐/青椒 + unknown |
| 决策 | 3 帧投票：过半且平均置信 ≥ 0.45、与第二名差 ≥ 0.12 才算「认出来」 | 不满足 → 标待确认，默认不加入库存 |
| 展示 | 「鸡蛋 86% · 3/3 帧一致」 | 2/3 一致会显示出来，行内标「待确认」 |
| 写库 | 一律不写；用户逐项确认后才走 `confirm_purchase` | 端侧识别只是草稿 |

**基线数字（来自 `models/food9_aug2_report.json`，16 张真实照片）**：整体约 50%，鸡蛋类 7/10。这就是为什么流程必须是「先猜、再确认」。

## 二、还没做的（明确的缺口）

| 缺口 | 为什么没做 | 怎么做 |
|---|---|---|
| 云端识别 | 需要视觉模型 API key 与一个 Edge Function | `recognize` 函数接收 Storage 里的图 → 调多模态模型 → 写 `capture_candidates`；前端只要把 `FDCLS.classify` 换成一次 fetch |
| 小票 OCR | 同上（同一套 Edge Function） | 表结构 `receipts` / `receipt_lines` 已就位，缺函数与对账界面 |
| 摄像头硬件 | 未采购；顶部俯拍能不能拍清还没验证 | 先 2 天实拍验证（见 Phase 0 文档第 5 节），再定 ESP32-S3-CAM / Pi Zero 2 W |
| 设备接入链路 | 依赖硬件 | 设计已定：设备持 `device_id + device_secret` 调 `device-ingest`，不持任何 Supabase key |
| 识别准确率 | 缺训练数据 | 见下节：确认数据已经在回流 |

## 三、识别准确率怎么真正提高（数据闭环已经具备）

用户每次确认采购，前端会写 `capture_candidates`：

- `raw_name` = 模型说的（预测）
- `food_id` = 用户最后选的（真值）
- `decision` = add / adjust / keep / ignore
- `confidence` = 当时的置信度

也就是说**「模型猜什么 / 人改成什么」已经成一对了**。用它可以做三件事：

```sql
-- 1) 混淆矩阵：哪两类最容易混（决定该补哪类数据）
select raw_name as predicted, food_id as actual, count(*) as n
  from capture_candidates
 where food_id is not null
 group by 1, 2
 order by n desc;

-- 2) 阈值校准：置信度落在哪一段时最容易被改
select width_bucket(confidence, 0, 1, 10) as band,
       count(*) as n,
       round(avg(case when food_id = raw_name then 1 else 0 end), 2) as hit_rate
  from capture_candidates
 where food_id is not null
 group by 1 order by 1;

-- 3) 类别分布：哪些类几乎没有样本（不会有好效果）
select food_id, count(*) from capture_candidates group by 1 order by 2 desc;
```

跑出来的结论会直接告诉我们：是补数据（第 1 条）、还是调阈值（第 2 条）、还是这个类干脆不做（第 3 条）。

## 四、诚实的一句话总结

**识别是「辅助录入」，不是卖点。** 现在的准确率只够支撑「帮你想一个候选，你点确认」，不够支撑「放进冰箱自动记上」。决策里定的是「只做采购入库辅助」，这条守住了；但要说「自动识别」，得先有云端模型 + 真实数据回流，两者都还没上。
