## 接线图（与仓库固件一致的交叉验证）

| 驱动板 | 开发板 GPIO |
|---|---|
| DC | GPIO6 |
| RST | GPIO10 |
| BUSY | GPIO0 |
| CS | GPIO7 |
| SCK/SCL | GPIO2 |
| SD/MOSI | GPIO3 |

→ 与 `firmware/FridgeOnline/FridgeOnline.ino` 的 `GxEPD2_420c_Z96(7,6,10,0)` + `SPI.begin(2,-1,3,7)` 完全一致。

## 刷机截图里出现的预设固件

`32-AirM2M-C3-266BWR-Stock-V20260512`（截图示例项，2.66″ 黑白红版本；下拉里应有 4.2″ Z96 对应项）。

## 对项目的结论

- 出厂固件是「股票显示器」，与本项目功能无关；我们的 Z96 驱动本来就来自资料1 的 Stock 工程。
- Hello World 页的 4.2″ 代码是 M01，不能用；真正可用的只有 Stock 工程里的 `GxEPD2_420c_Z96`。
- 刷回出厂固件只在退货 / 保修 / 想当股票屏用时才需要：gfldol.com → 预设固件 → 地址 0。
- 对设备端 HTTPS 连接重置（`tls=-80`）没有帮助。
