# 冰箱屏（电池版）按键行为

| 键 | GPIO | 行为 | 能否唤醒 |
|---|---|---|---|
| 左 | 4 | 短按：上一页 | ✅ |
| 中 | 5 | 短按：下一页（第 3 页再按回到第 1 页） | ✅ |
| 左/中 | 4/5 | **长按 ≥0.7 s**：立即刷新（不等 15 分钟定时） | ✅ |
| 右 | 13 | 唤醒后 0.7 s 内按下 = 刷新 | ❌ 不能唤醒（C3 只有 GPIO0–5 是深睡唤醒源） |

说明：

- 刷新如果没有新数据（304），固件会**重刷当前页**作为"确实刷新了"的反馈。
- 屏幕整刷约 4 秒，期间按键会被忽略。
- 翻页不联网、约 1 秒完成；刷新要联网，约 4–6 秒。

实测日志（2026-11-11）：

```
BOOT cause=7 / WAKE mask=0x10 prev=1 / DRAW page=2/3      ← 左键翻页
BOOT cause=7 / WAKE mask=0x20 next=1 / DRAW page=3/3→1/3  ← 中键翻页并循环
BOOT cause=7 / WAKE mask=0x20 next=1 / WAKE refresh requested
WIFI ok rssi=-63 / HTTPS http=304 / SYNC unchanged         ← 长按刷新
```
